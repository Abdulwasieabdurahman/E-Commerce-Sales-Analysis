# E-Commerce Sales Analysis

An interactive E-Commerce Sales Dashboard built with Power BI to analyze sales performance, profitability, products, categories, platforms, and geographic performance.

- Data Analysis

## Key Metrics

- Total Sales: 1.79M
- Gross Profit: 588.35K
- Profit Margin: 32.84%
- Units Sold: 6,490

## Analysis

The dashboard provides insights into:

- Sales and profit trends over time
- Sales performance by product category
- Sales and profit by platform
- Top 10 products by sales
- Country-level performance
- Global sales distribution
